# SPECTOR // 01 — CODE AFTER DARK

A cinematic, Marvel-inspired event landing page built for the GeeksforGeeks 
Student Chapter, Bennett University — Junior Core, Round 1 technical submission.

## Concept

SPECTOR // 01 reimagines Moon Knight's core theme of duality as the emotional 
core of a 12-hour overnight hackathon — the disciplined planner you are by day 
versus the version of you that ships at 2 a.m. under pressure. Instead of 
literal Marvel imagery, the design draws from Moon Knight's deeper visual DNA: 
Egyptian mythology, linen/bandage texture, crescent geometry, and a 
"classified operation" atmosphere.

**Design direction:** myth × machine — an editorial serif for mythic, oversized 
headlines, paired with monospace type for technical metadata and timestamps. 
A restrained obsidian/bone/silver palette, with gold used only as a rare accent.

- React + Vite
- Tailwind CSS
- Framer Motion (animations)
- Lucide React (icons)

## Fonts

- Cormorant Garamond — headings
- Manrope — body text
- IBM Plex Mono — metadata, timestamps, labels

## Assets

No stock photography or external imagery. All visuals — the hooded silhouette, 
lunar geometry, dust particles, grain texture — are custom-built with CSS/SVG.
